GUJARAT BAKERY WEBSITE
1. Open index.html in a browser to preview.
2. WhatsApp order number is set in js/app.js: SHOP_WHATSAPP = 917226839226.
3. Admin demo PIN is 2468 in js/app.js. Change ADMIN_PIN before publishing.
4. Admin panel opens from the footer -> Shop admin. Add/edit/delete products, import/export JSON.
5. Product changes are saved in this browser's localStorage only. They do not sync across devices.
6. This is a static front-end demo. The PIN is not secure authentication; do not treat it as a protected production admin panel.
7. Product names, prices and stock are sample values. Confirm and edit them to match the real bakery.
8. Replace sample image URLs with the bakery's own product image URLs when ready.
9. UPI option records the customer's preference only. It does not collect payment; confirm payment manually.
10. For a real shared admin panel and order dashboard across devices, add a backend/database and secure authentication.
